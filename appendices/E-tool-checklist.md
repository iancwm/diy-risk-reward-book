# Appendix E: Tool and Material Checklist

Use this before shopping. Check the task boundary first; a tool list is not permission to do regulated work.

## Core home kit

- [ ] Tape measure, pencil, small level
- [ ] Well-fitting screwdrivers and bits
- [ ] Adjustable spanner and pliers for appropriate non-regulated tasks
- [ ] Retractable utility knife and spare blades stored safely
- [ ] Stable step stool; no standing on chairs or furniture
- [ ] Torch, small tray, cloths, protective sheets, rubbish bags
- [ ] Eye protection and task-suitable gloves
- [ ] Product manuals, HDB rule links, and a place to save project photos

## Add only for a defined project

| Project | Confirm before buying | Possible items |
| --- | --- | --- |
| Interior painting | Dry sound surface; paint and primer compatibility | Roller, brush, tray, drop cloth, suitable filler/sanding block |
| Decorative caulking | Joint location, surface, movement, product cure | Caulk gun, removal tool, backing material if specified |
| Light-duty mounting | Wall type, load, HDB surface condition, concealed services | Drill/driver, correct bit, maker-approved fixing, level |
| Visible simple plumbing care | Exact PUB simple-work scope, working shutoff, matching part | Basin, cloth, correct spanner, seals specified by maker |
| Accessible drain clearing | Visible local debris; no chemicals or sewage exposure | Gloves, eye protection, small removal tool, plunger if suitable |
| Freestanding assembly | Maker's instructions and anti-tip requirement | Supplied fittings, correct driver, soft floor protection |

## Do not buy as a shortcut into a red task

- [ ] Electrical tester, multimeter, wire connectors, or panel tools for homeowner installation work
- [ ] Gas leak or pipe-working tools for gas service work
- [ ] Pipe-cutting or compression tools for concealed or regulated plumbing
- [ ] Waterproofing membrane products as a substitute for approved bathroom repair
- [ ] Demolition tools for structural or uncertain HDB elements
