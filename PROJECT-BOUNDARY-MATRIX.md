# Project boundary matrix — HDB draft

This table keeps the project chapters consistent. The colour applies to the **defined homeowner scope**, never to an entire trade. “Professional execution” means the project stays in the chapter for decision-making, but this book gives no homeowner execution method.

| Section | HDB homeowner scope | Draft classification | Main boundary / evidence |
| --- | --- | --- | --- |
| 5.1 Painting | Sound, dry interior wall | Green | Dampness, wider cracks, loose concrete → assessment. [HDB wall care](https://www.hdb.gov.sg/managing-my-home/renovation-and-maintenance/home-maintenance/home-care-guide/walls). |
| 5.2 Caulking | Dry-area visible decorative joint | Green | Suspected failed bathroom waterproofing → assessment. [HDB renovation information](https://www.hdb.gov.sg/managing-my-home/renovation-and-maintenance/renovation/important-information-on-renovations). |
| 5.3 Mounting | One light item on confirmed wall/fixing | Green | Heavy load, household-shelter uncertainty, concealed services → yellow/pro. [HDB building works](https://www.hdb.gov.sg/managing-my-home/renovation-and-maintenance/renovation/renovation-guidelines/building-works). |
| 5.4 Hardware | Cabinet/furniture fitting using existing holes | Green | Electrical, window, security, or wall-mounted fitting → separate scope. |
| 5.5 Fixture care | Visible listed simple accessory | Green | Pipe, valve, hidden leak, toilet-bowl replacement → licensed assessment. [PUB simple-work list](https://www.pub.gov.sg/Professionals/Requirements/Licensed-Plumbers/Plumbing-Works). |
| 5.6 Drain clearing | Visible floor-trap debris or strainer | Green | Serious or recurring blockage, sewage → plumber. [HDB floor-trap care](https://www.hdb.gov.sg/managing-my-home/renovation-and-maintenance/home-maintenance/home-care-guide/floor-traps). |
| 5.7 Smart plug-ins | Plug-in or battery product | Green | Fixed wiring → Licensed Electrical Worker. [EMA](https://www.ema.gov.sg/consumer-information/electricity/engaging-licensed-workers). |
| 5.8 Furniture | Freestanding assembly | Green | Required anchoring or wall-hung storage → mounting assessment. |
| 5.9 Appliance maintenance | User-serviceable filter/surface | Green | Exterior air-con unit, gas, refrigerant, control board → professional. [HDB air-con care](https://www.hdb.gov.sg/managing-my-home/renovation-and-maintenance/home-maintenance/home-care-guide/air-conditioners). |
| 5.10 Weatherstripping | Removable interior door strip | Green | Window repair, ventilation, fire/shelter door → professional/rules check. [HDB windows](https://www.hdb.gov.sg/managing-my-home/renovation-and-maintenance/home-maintenance/home-care-guide/windows). |
| 5.11 Outdoor upkeep | Brief transfer example only | Exception | Typical HDB facade/common-property work is outside homeowner scope. |
| 6.1 Tap/toilet/disposal | Accessible like-for-like tap | Yellow | Toilet bowl and new drainage/electrical work → licensed/professional scope. [PUB](https://www.pub.gov.sg/Professionals/Requirements/Licensed-Plumbers/Plumbing-Works). |
| 6.2 Electrical replacements | Brief, hire, and verify | Professional execution | EMA Licensed Electrical Worker for installation work. [EMA](https://www.ema.gov.sg/consumer-information/electricity/engaging-licensed-workers). |
| 6.3 Drywall repair | Small dry non-structural board patch | Yellow | Services, dampness, concrete, movement → assessment. |
| 6.4 Backsplash | Small dry kitchen wall finish within HDB rules | Yellow | Finish replacement, wet area, hacking, electrical alteration → approval/pro. [HDB building works](https://www.hdb.gov.sg/managing-my-home/renovation-and-maintenance/renovation/renovation-guidelines/building-works). |
| 6.5 Smart controls | Battery/plug-in device plus mounting/privacy check | Yellow | Hardwired control/doorbell → Licensed Electrical Worker. [EMA](https://www.ema.gov.sg/consumer-information/electricity/engaging-licensed-workers). |
| 6.6 Exterior sealing | Observe, document, brief repair | Professional execution | Exterior window/facade work is not a casual caulk job. [HDB windows](https://www.hdb.gov.sg/managing-my-home/renovation-and-maintenance/home-maintenance/home-care-guide/windows). |
| 6.7 Floating shelves | Modest shelf on confirmed wall/load | Yellow | Heavy/overhead load or uncertain substrate/services → professional. [HDB building works](https://www.hdb.gov.sg/managing-my-home/renovation-and-maintenance/renovation/renovation-guidelines/building-works). |
| 6.8 Supply hose | Visible listed flexible hose | Yellow | Stop valve, fixed/hidden pipe, corrosion → Licensed Plumber. [PUB](https://www.pub.gov.sg/Professionals/Requirements/Licensed-Plumbers/Plumbing-Works). |
| 6.9 Appliance installation | Existing suitable connections; documented scope | Yellow | Gas, fixed wiring, new drain, exterior air-con → appropriate professional. [EMA](https://www.ema.gov.sg/consumer-information/electricity/engaging-licensed-workers), [HDB](https://www.hdb.gov.sg/managing-my-home/renovation-and-maintenance/home-maintenance/home-care-guide/air-conditioners). |
| 6.10 Deck/fence staining | Brief transfer example only | Exception | Not a typical HDB-flat feature. |

**Open before publication:** The wording for homeowners personally doing a PUB-listed “simple plumbing work” should be checked against the current full legal and HDB context. Material budgets need a dated Singapore price basket; the chapter's time bands are editorial allowances, not measured data. A qualified trade reviewer should assess the final electrical, plumbing, mounting, and wet-area boundaries.
