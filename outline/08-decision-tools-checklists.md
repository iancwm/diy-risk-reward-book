# 8. Decision Tools and Checklists
## 8.1 Green/Yellow/Red Checklist
- Is it visible and accessible?
- Can I shut off water/power?
- Is it reversible?
- Does it need a permit?
- Could failure cause fire, flood, gas, collapse, or mold?
- Will insurance cover a mistake?
- Do I have the right tools and test equipment?

## 8.2 Pre-Project Risk Assessment Form
- Project description
- Risk category
- Permit required?
- Shutoffs identified?
- PPE ready?
- Pro backup identified?
- Stop-work triggers
- Documentation plan

## 8.3 Permit Trigger List
- Electrical, plumbing, structural, gas, HVAC, waterproofing, additions.

## 8.4 When to Stop and Call a Pro
- Burning smell, repeated breaker trips, no shutoff, sewage, gas smell, hidden leak, structural crack, mold, asbestos, lead.
