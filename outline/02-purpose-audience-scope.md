# 2. Purpose, Audience, and Scope
- **Purpose:** Give homeowners a practical framework for choosing DIY projects.
- **Audience:** First-time DIYers, experienced homeowners, renters where allowed, property managers.
- **Scope:** Residential maintenance, repair, and improvement.
- **Exclusions:** Commercial work, gas, mains electrical, structural engineering, HVAC refrigerant, regulated asbestos/lead/mold.
- **Method:** Risk-reward matrix based on likelihood, severity, detectability, reversibility, code impact, insurance impact, and skill/tool requirements.
