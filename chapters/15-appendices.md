# 15. Guide to the Appendices

The appendices are working pages. Use them for a specific flat and project, then date your entries. They do not grant approval or replace the current HDB guideline, licensed-worker requirement, manufacturer instruction, or site assessment.

| If you need to… | Use… | What it helps you record |
| --- | --- | --- |
| See the book's project categories at a glance | [A. Green/Yellow/Red master table](../appendices/A-master-table.md) | The default colour and the condition that changes it |
| Decide whether a defined job is suitable | [B. Project risk assessment form](../appendices/B-risk-assessment-form.md) | Scope, failure path, control, stop sign, and result check |
| Check the authority and worker boundary | [C. Permit trigger checklist](../appendices/C-permit-trigger-checklist.md) | HDB approval, conditions, licence, and completion evidence |
| Prepare for a leak or service problem | [D. Emergency shutoff map](../appendices/D-emergency-shutoff-map.md) | Flat-specific control locations and contacts |
| Assemble a small, suitable kit | [E. Tool checklist](../appendices/E-tool-checklist.md) | Tools owned, borrowed, or supplied by a professional |
| Decode an unfamiliar term | [F. Glossary](../appendices/F-glossary.md) | Plain-language meanings in this HDB setting |
| Check the source behind a claim | [G. References and standards](../appendices/G-references-and-standards.md) | Official pages, standards listings, and dated retail inputs |
| Turn a decision into a project brief | [H. Sample project plans](../appendices/H-sample-project-plans.md) | Three illustrative filled plans and a reusable blank plan |

For a new project, start with B and C, then write the plan using H. Keep the completed pages with photographs, quotes, approvals, invoices, and test or warranty documents. Revisit the forms if the site reveals a different scope.
